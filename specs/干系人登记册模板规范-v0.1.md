# 干系人登记册模板规范 v0.1

## 目标

验证“项目章程与风险信息 → 识别干系人 → 权力利益分类 → 参与差距 → 管理策略”的连续推演。

## 三个同步视图

1. 干系人登记册：动态行，记录基本信息、评估信息、分类信息和来源依据。
2. 权力利益方格：权力和利益均使用 1–5 级，4–5 视为高，1–3 视为低。
3. 参与度评估矩阵：同时标记当前参与程度 C 和期望参与程度 D。

## 权力利益分类

- 高权力、高利益：重点管理。
- 高权力、低利益：令其满意。
- 低权力、高利益：随时告知。
- 低权力、低利益：监督。

分类由权力和利益数值自动计算，不允许手工覆盖。修改任一分值后，方格位置、登记册分类和汇总数量必须同步更新。

## 参与程度

顺序为：不了解、抵制、中立、支持、领导。C 表示当前参与程度，D 表示项目所需参与程度。同一位置显示 `CD`；D 高于 C 时产生参与差距，并要求给出管理策略。

## 来源与隐私

原型阶段使用角色和组织群体，不写入真实姓名、电话或邮箱。每一行保留 `sourceIds`，指向访谈答案、章程字段、推理节点或风险编号。未来加入登录和权限后，再支持个人联系方式与敏感字段分级访问。

## 产品联动

- 从项目章程读取发起人、项目经理、用户和交付责任角色。
- 从风险登记册读取安全、合规、供应商、技术和发布责任角色。
- 点击“查看知识依据”进入识别干系人、干系人登记册、权力利益方格或参与度评估矩阵的知识档案。
- 知识档案中的“在汽车案例中查看”返回本样本。
