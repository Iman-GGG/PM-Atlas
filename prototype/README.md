# PM Atlas 原型

面向刚入行项目经理的项目管理知识库与项目实验室。

## 一级入口

- 知识库：管理活动地图、文档触点地图、知识关系图谱和知识档案四个可定位标签；触点地图平铺 49 个子活动，并使用紧凑、清晰的文档触点单元。
- 项目实验室：第一级为立项和十大管理领域 11 个标签；第二级只读展示 49 个管理子活动；下方呈现主要输入、输出和 BIM 规划报建案例成果。

## 当前项目实验室成果

- 项目章程：访谈、推理树和实时预览。
- 风险登记册：动态行、固有/剩余评分和概率影响矩阵。
- 干系人登记册：权力利益方格、参与程度差距和动态行编辑。
- 其余七个管理领域：用统一的输入 → 管理活动 → 输出结构展示全部子活动。

实践页面不再跨空间跳转到知识库；知识库中的地图、图谱和档案仍在知识库内部连续探索。

## 运行

需要 Node.js 22.13 或更高版本。

```bash
pnpm install
pnpm run dev
pnpm run build
```

本地访问 `http://localhost:3000`。原型暂时免登录，数据交互保存在页面内存中；后续接入持久化和登录能力。
