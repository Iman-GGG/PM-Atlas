# PM Atlas 原型

面向刚入行项目经理的项目管理知识库与项目实验室。

## 一级入口

- 知识库：管理活动地图、文档触点地图、知识关系图谱和知识档案四个可定位标签；触点地图平铺 49 个子活动，并使用紧凑、清晰的文档触点单元。
- 项目实验室：第一级为立项和十大管理领域 11 个标签；第二级只读展示 49 个管理子活动；下方呈现主要输入、输出和 BIM 规划报建案例成果。

## 当前项目实验室成果

- 项目章程：访谈、推理树和实时预览。
- 风险登记册：动态行、固有/剩余评分和概率影响矩阵。
- 干系人登记册：权力利益方格、参与程度差距和动态行编辑。
- 其余七个管理领域：用统一的输入 → 管理活动 → 输出结构展示全部子活动。

实践页面不再跨空间跳转到知识库；知识库中的地图、图谱和档案仍在知识库内部连续探索。

## 运行

需要 Node.js 22.13 或更高版本。

```bash
pnpm install
pnpm run dev
pnpm run build
```

本地访问 `http://localhost:3000`。公开主线免登录浏览；创建与切换个人分支、查看受限文件和 AI 复盘需要 ChatGPT 登录，学习进度保存在 D1。

## 站点统计

管理员登录后可访问 `/stats` 查看登录用户、日活、分支创建、AI 复盘请求和情景材料首次查看等汇总数据。统计接口会再次执行服务端权限校验；部署环境必须配置：

```text
ANALYTICS_ADMIN_EMAILS=owner@example.com
```

多个管理员邮箱以英文逗号分隔。未登录浏览不建立分析身份；统计不保存原始 IP、页面输入或行动链具体内容。登录访问与日活从统计功能上线后开始记录，历史 AI 复盘记录会在数据库迁移时按已有记录补入一次。
